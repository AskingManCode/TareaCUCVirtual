# Propuesta de rediseño del Sitio Web Principal del CUC (CUC Virtual) 

## Descripción del Proyecto

Este proyecto contiene el prototipo web desarrollado para la propuesta de mejora y rediseño del sitio web principal del **Colegio Universitario de Cartago**.

Esta es una tarea asignada del curso Administración y Programación de Sitios Web, de la carrera de Tecnologías de la Información.

## Estructura del Proyecto

La estructura de carpetas y archivos del proyecto están organizado de la siguiente manera:

```
TareaCUCVirtual.
|---README.md
|   
|---CUCVirtualPage
|   |---index.html
|   |---carreras.html
|   |---general.html
|   |---scripts.js
|   |---styles.css
|       
|---Documentacion
|   |---1. Tarea Corta #1.pdf
|       
|---Pruebas Tecnicas
    |---Pruebas Tecnicas.docx
```

## Tecnologías Utilizadas

* HTML5
* CSS
* JavaScript

## Instrucciones de Uso y Ejecución

1. Clonar o descargar el repositorio.
2. Navegar a la carpeta del proyecto: `TareaCUCVirtual/CUCVirtualPage`.
3. Ejecutar el prototipo: Abrir el archivo `index.html` directamente en cualquier navegador (no requiere servidor ni librerías adicionales).
